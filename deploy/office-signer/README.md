# Офисный подписант УКЭП (agent.ps1)

Маленький агент для Windows-компьютера, где стоят КриптоПро CSP и УКЭП
(тот, с которого заходят в ЛК Честного знака). Он опрашивает сервер стража
по HTTPS и подписывает данные локально: **ключ УКЭП никуда не передаётся**,
входящих подключений к офисному компьютеру нет.

Зачем: авторизация интеграции в True API Честного знака (сверка остатков,
статусы кодов) требует подписи УКЭП; сервер за границей и ключа не имеет.

## Установка (5 минут)

1. Скачайте файл `agent.ps1` из этой папки репозитория на офисный компьютер,
   например в `C:\cosmex-signer\agent.ps1`.
2. Откройте его блокнотом и заполните три строки в блоке НАСТРОЙКИ:
   - `$Secret` — секрет подписанта (выдаёт интеграция; печатается при деплое);
   - `$CertName` — часть имени сертификата УКЭП. Посмотреть имя:
     Пуск → «Панель управления КриптоПро» → вкладка «Сертификаты», либо
     `certmgr.msc` → Личное → Сертификаты. Достаточно уникального фрагмента
     (обычно — название организации или ФИО владельца);
   - `$CspTest` — путь к csptest.exe (по умолчанию верен для стандартной
     установки КриптоПро CSP 5).
3. Проверка подписи (PowerShell от имени того пользователя, у кого сертификат):

   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\cosmex-signer\agent.ps1 -Test
   ```

   Должно напечатать «ОК: подпись получена». Если КриптоПро спросит PIN —
   введите и поставьте галочку «Запомнить», иначе агент будет виснуть на
   запросе PIN при каждой подписи.
4. Запуск агента:

   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\cosmex-signer\agent.ps1
   ```

   Окно можно свернуть. Журнал пишется в `agent.log` рядом со скриптом.

## Автозапуск при входе в систему (по желанию)

Планировщик заданий → Создать простую задачу → «При входе в систему» →
Запустить программу:
- Программа: `powershell.exe`
- Аргументы: `-WindowStyle Hidden -ExecutionPolicy Bypass -File C:\cosmex-signer\agent.ps1`

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `-Test` пишет «не удаётся найти указанный файл» | Неверный путь `$CspTest` — найдите csptest.exe в папке установки КриптоПро |
| «0x8010006E / отменено пользователем» | Появился запрос PIN — запустите `-Test`, введите PIN с галочкой «Запомнить» |
| «сертификат не найден» | `$CertName` не совпадает — возьмите точный фрагмент CN из certmgr; сертификат должен быть в хранилище «Личное» текущего пользователя, Рутокен вставлен |
| Агент пишет «Связь с сервером… повтор» | Нет интернета/сервер недоступен — агент сам переподключится |
| HTTP 403 при опросе | Не совпадает `$Secret` с SIGNER_SECRET на сервере |

## Безопасность

- Агент делает только исходящие HTTPS-запросы к серверу стража.
- Наружу уходит только готовая подпись конкретных данных; закрытый ключ
  не читается и не копируется.
- Компьютер должен быть включён в моменты, когда интеграция выполняет
  операции с Честным знаком (сверки по расписанию — днём в рабочие часы).
