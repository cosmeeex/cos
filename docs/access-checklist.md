# Что нужно от владельца для запуска

Порядок = порядок запуска. Первые два пункта позволяют запустить аудит и стража уже в день выдачи.

## 1. МойСклад (запускает: аудит, страж, план остатков, монитор дистанционных продаж)

- [ ] **Токен API**: МойСклад → Настройки → Обмен данными → Токены → создать для отдельного сотрудника-робота «Интеграция маркировки» (права: товары, документы закупок/продаж, розница, маркировка, отчёты остатков, вебхуки). Токен → `MOYSKLAD_TOKEN` в `.env`.
  ⚠️ Не создавайте токен от личного аккаунта владельца: `POST /security/token` отзывает предыдущие токены пользователя.
- [ ] Подтвердить, что на аккаунте активны: платный тариф + опция **«Маркировка»** (~700 ₽/мес), решение «Честный знак» подключено (Решения → Честный знак).
- [ ] Название юрлица/ИП, с которого ведётся торговля (для документов маркировки), и ИНН → `CRPT_INN`.

## 2. Сервер для стража (вебхуки + панель)

- [ ] Любой VPS/машина с Node.js ≥22.18 и публичным HTTPS-URL (достаточно 1 CPU / 512 МБ; подойдёт и сервер, где крутится cosmex.ru).
- [ ] Придумать `WEBHOOK_SECRET` (любая случайная строка).
- [ ] После запуска: `node src/cli.ts setup-webhooks https://<домен-стража>` — включит вебхуки.

## 3. Честный знак — ЛК (запускает: сверку остатков, прямые проверки кодов)

- [ ] Подтверждение, что организация зарегистрирована в ГИС МТ и подключены товарные группы: «Косметика и бытовая химия» (+ «Парфюмерия», если мисты окажутся 3303; + «Антисептики», если торгуем; + «Личная гигиена» — регистрация откроется 01.09.2026).
- [ ] **УКЭП** организации (КриптоПро CSP) на машине, где будет работать интеграция, отпечаток сертификата → `CRPT_CERT_THUMBPRINT`, команда подписи → `CRPT_SIGNER_CMD`. Если УКЭП нельзя выносить с рабочего места бухгалтера — обсудим схему «подписант на той машине» (интеграция умеет вызывать внешний подписант).
- [ ] Либо (проще для старта): **API-ключ ЛК ЧЗ / выгрузка CSV отчёта «Коды в обороте»** раз в неделю — сверка заработает и без УКЭП на сервере.
- [ ] Для заказа кодов напрямую (минуя UI МойСклад, опционально): ЛК ЧЗ → Управление заказами → Устройства → `CRPT_OMS_ID`, `CRPT_OMS_TOKEN`.
- [ ] Пополненный лицевой счёт ЧЗ (эмиссия: 0,61 ₽/код с НДС 22%).

## 4. Касса и разрешительный режим

- [ ] Подтвердить: ККТ с **ФФД 1.2**, 2D-сканеры на всех кассах и на складе сборки интернет-заказов.
- [ ] ЛК ЧЗ → Маркировка → Данные участника → **«Токен для ККТ»** → вставить в МойСклад (карточка юрлица → Маркировка). Один токен на ИНН.
- [ ] В точках продаж МойСклад включить: «работа с маркировкой», режим **«Только с правильными кодами»**; для офлайн-проверки нужна Windows-касса с «Локальным модулем ЧЗ» (обязательно к 01.04.2027).

## 5. ЭДО

- [ ] Какой оператор ЭДО используется (ЭДО Лайт / Такском / Диадог через 1С)? Логин/доступ для импорта УПД в МойСклад.
- [ ] Список основных поставщиков маркируемого товара — проверим, что все передают УПД с кодами.

## Что НЕ нужно

- Пароли от ЛК Честного знака и Госуслуг — не нужны, всё делается УКЭП/токенами.
- Доступ к кассам — настройки делаются в МойСклад.
