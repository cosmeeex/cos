# Ассортимент cosmex.ru применительно к маркировке «Честный знак»

**Дата анализа:** 19.08.2026. **Метод:** главная страница, sitemap.xml (полная выгрузка, 6 354 карточки), страницы категорий/подкатегорий, выборочные карточки товаров.

**Ключевой вывод:** cosmex.ru — **не парфюмерный магазин**, а магазин товаров для ногтевого сервиса и салонов красоты (Новосибирск, есть B2B/опт). Классической парфюмерии (духи, EDP, EDT, одеколоны) **нет вообще**; ядро ассортимента — гель-лаки и инструменты. Под текущую/будущую маркировку косметики попадает **~41% ассортимента (~2 600 SKU)**.

## 2–3. Классификация по группам «Честного знака» и коды ТН ВЭД

### (а) Парфюмерия — ТН ВЭД 3303 (маркировка обязательна с 2020 г.)
**Классической парфюмерии нет: 0 SKU.** Ни духов, ни парфюмерной/туалетной воды, ни одеколонов, ни тестеров, ни распивов/отливантов.
**Бывшая риск-зона (~8 SKU) — снята 19.08.2026:** парфюмированные **мисты для тела и волос** COSMEX NOIR «по мотивам» известных ароматов (Baccarat Rouge 540, Lost Cherry, Kirke, L'Imperatrice, Molecule 02), 250 мл, ~450 ₽. **Владелец подтвердил: мисты неспиртовые** → классифицируются как косметика (3307/3304, волны 2025 г.), а не парфюмерия 3303. Точный код — из деклараций (проставить в карточках при аудите). Производство — Казахстан (импорт, ЕАЭС): маркирует Cosmex как импортёр. Если в ассортименте когда-нибудь появится спиртовой мист/арома-спрей — он попадёт в 3303, где правила жёстче.
Пример: https://cosmex.ru/product/cosmex-noir-parfumed-mist-amber-rouge-po-motivam-baccarat-parfyumirovannyy-mist-dlya-tela-i-volos-am-038e4153-7e74-11f0-0a80-0275000aaa8a

### (б) Косметика по уходу — ТН ВЭД 3304 (~2 100 SKU, ~33%)
Крупнейшая маркируемая группа — **средства для маникюра относятся к 3304** (код 3304 30 000 0 «средства для маникюра или педикюра»):
- Гель-лаки: ~1 061 (COSMEX, BSG, CosmoLac, KIRA, Lovely, ADRICOCO, Planet Nails; 7–15 мл, 99–616 ₽)
- Базы, топы, праймеры, дегидраторы: ~374
- Лаки для ногтей: ~116 (в т.ч. BAL mini 6 мл)
- Гели/акрилы для наращивания: ~183
- Уход за кожей (3304 99): кремы ~136 (MILV), масла для кутикулы ~160 (OPI, MILV, Smart), сыворотки/тоники ~28 (Cos De Baha, COSMEX Derma), маски для лица ~28 (EKEL, ARAVIA), скрабы/парафин ~12, пенки ~14, бальзамы для губ (Hurraw!)

### (в) Декоративная косметика — ТН ВЭД 3304 (~10–50 SKU, <1%)
Минимальна: жидкие тени LUXVISAGE Matt Tint (~5 SKU), точилки/аксессуары Ellis Cosmetic.

### (г) Средства для волос — ТН ВЭД 3305 (~410 SKU, ~6,5%)
- Шампуни/бальзамы/кондиционеры: ~233 (COSMEX OverDose, Constant Delight 1000 мл, парфюмированные шампуни NOIR/Syre 300 мл)
- Маски для волос, ламинирование: ~30 (COSMEX Parfumed Hair Mask, ESTEL Prima Blond)
- Краски и осветление: ~149 (Kapous, ESTEL, OLLIN)

### (д) Гигиена/мыло — ТН ВЭД 3401 (частично 3307) (~90 SKU, ~1,4%)
- Гели для душа парфюмированные COSMEX NOIR/Syre, 300 мл (~70 SKU) — 3401 30 000 0
- Жидкое мыло для рук NOIR 500 мл (~6 SKU), твёрдое мыло Camel Soap Factory, твёрдый кондиционер-бар — 3401

### (е) Бытовая химия
**Бытовой химии для дома нет.** Есть **профессиональная дезинфекция** (~17–30 SKU): кожные антисептики и дезрастворы Алмадез, Оптимакс, Аламинол — это **ТН ВЭД 3808**: кожные антисептики подпадают под **собственную маркировку (обязательна с 2024 г.)** — отдельный контур учёта.

### (ж) Прочее — НЕ подлежит маркировке (~3 600–3 700 SKU, ~57%)
Инструменты (Staleks, Hanzo), фрезы/боры/полиры (~2 200), оборудование (Strong, Marathon, SUN UV), дизайн ногтей (стразы, слайдеры ~490), типсы/формы, кисти/спонжи, расходники (перчатки Benovy, крафт-пакеты), униформа. Также **свечи COSMEX NOIR и отдушки (~66 SKU)** — ТН ВЭД 3406/3307 49, не маркируются.
