## Решение по массовому исправлению признаков — ожидает владельца

`audit --fix` готов проставить признак маркировки на **2 283 карточки** (уверенность классификатора ≥ 0.75).

⚠️ Важно понимать последствие: как только у товара появляется признак маркировки, **Касса МойСклад начинает требовать сканирование DataMatrix при продаже**. Для товара, выпущенного до волны (законные немаркированные остатки), кода на упаковке нет — кассир должен уметь провести такую продажу по регламенту остатков (или в настройках точки временно разрешить продажу без кода). Поэтому включение — либо разом с инструктажем кассиров, либо поэтапно (сначала СТМ Cosmex, затем остальное).
