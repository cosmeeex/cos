# ЭТрН (электронная транспортная накладная): что это и что делать Cosmex

Дата исследования: 27.08.2026. Обязательность — с **01.09.2026**, штрафы — после
**01.03.2027** (переходный период; мораторий анонсирован, но акт на дату
исследования не принят — тянуть до марта не стоит).

## Суть

С 01.09.2026 все коммерческие автоперевозки грузов оформляются электронной
транспортной накладной вместо бумажной. Документы уходят в государственную
систему **ГИС ЭПД** через коммерческих **операторов ИС ЭПД** (реестр Минтранса).
Напрямую с ГИС ЭПД никто не работает — только через оператора.

Накладная подписывается по этапам («титулы»):

| Титул | Кто подписывает | Когда | Подпись |
|---|---|---|---|
| Т1 — данные о грузе и маршруте | Грузоотправитель | до погрузки | УКЭП (или УНЭП/Госключ), для сотрудника + МЧД |
| Т2 — погрузка | Перевозчик (водитель подтверждает в приложении) | при погрузке | УКЭП перевозчика, ПЭП водителя |
| Т3 — приёмка | Грузополучатель | при получении | УКЭП |
| Т4 — выгрузка | Перевозчик | при выгрузке | УКЭП |

## Когда ЭТрН НЕ нужна (важно для нас)

- **Свой товар — своим транспортом** (водитель в штате/свой автомобиль):
  накладная не оформляется вообще, достаточно путевого листа. Развоз по своим
  точкам своим транспортом — вне ЭТрН.
- **Перевозка между своими складами** (отправитель = получатель) — исключение,
  ЭТрН нужна только если нанимается сторонний перевозчик.
- **Заказчик — физлицо для личных нужд** (клиент сам заказал и оплатил доставку
  у перевозчика).
- Международное плечо (Казахстан → РФ) — там CMR; ЭТрН нужна только на
  российский участок, если он оформляется отдельным договором перевозки.

## Когда ЭТрН появляется у Cosmex

| Сценарий | Кто оформляет Т1 | Что делать нам |
|---|---|---|
| Отправка через экспедитора со сборным грузом (СДЭК, Деловые линии, КИТ и т.п.), экспедитор принимает груз во владение и выдаёт экспедиторскую расписку | **Экспедитор** (с признаком «является экспедитором») | Подписывать электронные **экспедиторские документы** (заявка/расписка) в сервисе ТК или через ЭДО. Своего оператора ИС ЭПД для этого обычно не нужно |
| Наёмный перевозчик по договору перевозки (машина под наш груз: опт клиенту, перемещение между складами наёмным транспортом) | **Cosmex как грузоотправитель** | Нужны: оператор ИС ЭПД, УКЭП (уже есть — используется для ЧЗ/ЭДО), МЧД на сотрудника |
| Интернет-заказы курьерскими службами по договору экспедиции | ТК/курьерская служба | Как правило, ничего; уточнить письмом (шаблон ниже) |
| Приёмка грузов от поставщиков | Поставщик/его экспедитор | Подписать Т3 при получении — через оператора (роуминг работает между всеми операторами) |

Ключевой практический вывод: **роль зависит от договора с конкретной ТК**.
Первый шаг — письменный запрос каждой ТК (шаблон ниже), их ответ определяет,
нужен ли нам вообще свой кабинет оператора ИС ЭПД.

## Шаблон письма транспортной компании

> Тема: Порядок оформления ЭПД с 01.09.2026
>
> Здравствуйте! Мы, ООО/ИП COSMEX (ИНН 421715237155), отправляем грузы через
> вашу компанию. Просим до 01.09.2026 письменно описать порядок оформления
> электронных перевозочных документов по нашим отправкам:
> 1. ваша роль по договору с нами — перевозчик или экспедитор;
> 2. кто формирует и подписывает Т1 ЭТрН / экспедиторские документы;
> 3. какой оператор ИС ЭПД используется, нужен ли нам собственный оператор
>    или подписание идёт в вашем личном кабинете;
> 4. что требуется от нас (подпись, МЧД, регистрация) и порядок тестового
>    обмена.

## Подключение (если/когда понадобится свой оператор)

1. УКЭП руководителя — **уже есть** (используется для Честного знака и ЭДО).
   Альтернатива для сотрудников на выезде — бесплатная УНЭП через «Госключ».
2. МЧД на сотрудника, который будет подписывать накладные (выпускается в
   сервисе оператора за ~15 минут).
3. Договор с оператором ИС ЭПД. Рекомендация: **Контур.Логистика** — есть
   открытый API (наша интеграция сможет создавать черновики автоматически),
   офлайн-мобильное приложение, роуминг со всеми операторами. Альтернативы:
   СБИС, Такском-Транспорт, Астрал/1С-ЭПД (тарифы порядка единиц рублей за
   документ, подключение от нуля до нескольких тысяч рублей в год).
4. Тестовый обмен с основной ТК → рабочий режим.

Регистрация в реестре экспедиторов (ГосЛог) нам **не нужна** — мы не оказываем
экспедиторские услуги третьим лицам. Учётная запись в ГИС ЭПД появляется
автоматически через оператора.

## Автоматизация в нашей интеграции (план)

Этап A — сейчас, без оператора:
- SOP для сотрудников (docs/sop/80-etrn.md): по каждому виду отправки — что
  подписывать и где; ничего не отправлять «по-старому» без документов.
- Разослать письма ТК, собрать ответы, определить: нужен ли свой оператор.

Этап B — после выбора оператора:
- Команда `etrn-draft <отгрузка>`: по Отгрузке МойСклад интеграция сама
  собирает данные для Т1 — грузополучатель и адрес из контрагента, перечень
  груза, число мест, масса (из карточек товаров) — и готовит черновик:
  сначала файлом для вставки в кабинет оператора, после подключения API —
  создание черновика прямо у оператора. Человеку остаётся проверить и нажать
  «Подписать» (подпись по закону ставится живой УКЭП — этот шаг
  автоматизировать нельзя).
- Страж: отгрузка с признаком «доставка наёмным транспортом» без связанной
  ЭТрН → жёлтое предупреждение в Telegram (по аналогии с контролем «вывода из
  оборота» для дистанционных продаж).
- Контроль Т3: напоминание подписать приёмку по входящим грузам.
