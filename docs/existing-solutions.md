# Маркировка «Честный знак» + МойСклад: обзор решений, must-have функционал, антиошибки, UX

**Контекст:** cosmex.ru работает на МойСклад + Касса МойСклад. Косметика вошла в обязательную маркировку поэтапно в 2025 г. (бытовая химия/мыло — с 01.05.2025; средства для волос, бритья, дезодоранты — с 01.07.2025; декоративная и уходовая косметика, средства для полости рта — с 01.10.2025). Ключевой рубеж — **1 июля 2026**: обязательные ЭДО при приемке/отгрузке и передача сведений о выводе из оборота через кассу; объемно-сортовой учет действует до 30.06.2028, далее — поэкземплярный. С **1 сентября 2026** запускаются автоштрафы по данным касс без выездных проверок. Парфюмерия маркируется давно (оборот немаркированной запрещен с 01.10.2021), там уже действует поэкземплярный учет и разрешительный режим.

---

## 1. Обзор решений

### 1.1. Нативная маркировка в МойСклад (база, уже есть у cosmex)

МойСклад — официальный партнер «Честного знака»; встроенное бесплатное приложение «Честный знак» ставится из раздела «Приложения» и закрывает полный цикл: заказ КМ и печать этикеток из интерфейса (без входа в ЛК ЧЗ), маркировка остатков, приемка по УПД через ЭДО с проверкой кодов, отгрузка с КМ, вывод из оборота при продаже через Кассу МойСклад, объемно-сортовой и поэкземплярный учет, работа с 2D-сканерами и ТСД (приложение ставится, например, на АТОЛ Smart.Lite; есть инвентаризация со списком расхождений). Для разрешительного режима на кассе: онлайн-проверка через ключ API ГИС МТ, офлайн — через «Локальный модуль ЧЗ» (только Windows 10+; на iOS — только онлайн, macOS/Linux не поддерживаются). Полный функционал маркировки требует тарифа не ниже «Профессионального».

Контур и СБИС — сильные по функционалу, но живут в своих экосистемах.

## 2. Must-have функционал (выжимка из лучших решений)

1. **Проверка кодов при приемке (сверка скана с УПД)** — сканирование каждого КМ (или выборочная проверка при ОСУ) и автоматическая сверка с кодами в УПД до подписания; проверка статуса кода в ГИС МТ («в обороте», принадлежность поставщику).
2. **Разрешительный режим на кассе (онлайн + офлайн)** — проверка перед продажей: код есть в ЧЗ, введен в оборот, не выведен, не просрочен, не заблокирован, криптоподпись валидна. С 01.07.2026 кассовое ПО обязано работать через модуль ТС ПИоТ. Офлайн-резерв — Локальный модуль ЧЗ (у МС требует Windows-кассы).
3. **Вывод из оборота для дистанционной торговли** — при курьерке/собственном ПВЗ чек с КМ пробивает магазин; при продаже через агента — агент; при отгрузке со склада есть 3 дня на передачу сведений с причиной «дистанционный способ продажи». Решение должно сканировать КМ на этапе сборки заказа и автоматически формировать вывод из оборота.
4. **Сверка остатков с ГИС МТ** — регулярное сравнение количества КМ «в обороте» по каждому GTIN с остатками учетной системы + инвентаризация КМ сканированием с отчетом о расхождениях.
5. **Массовый заказ КМ и маркировка остатков/перемаркировка** — заказ кодов пакетно (в т.ч. из Excel), ввод в оборот, перемаркировка при повреждении этикетки.
6. **Печать этикеток** — шаблоны, массовая печать, допечать дубликата по скану, печать на остатки.
7. **Работа с ТСД** — приемка/сборка/отгрузка/инвентаризация со сканированием, офлайн-режим.
8. **Мониторинг статусов и «контроль ошибок»** — дашборд: неподписанные УПД (срок!), коды с некорректным статусом, расхождения, зависшие выводы из оборота.
9. **ЭДО внутри контура** — приемка/отгрузка УПД с кодами без ручного переноса (обязательно с 01.07.2026).

## 3. Типичные ошибки ритейлеров → штрафы → механизмы контроля

| Ошибка (из практики) | Последствие | Механизм предотвращения |
|---|---|---|
| Продажа «чужого» кода (код числится за поставщиком/другой точкой, УПД не принят) | Штраф за нарушение оборота: ИП до 10 тыс., юрлица 50–300 тыс. руб. + конфискация | Запрет продажи товара, чей КМ не «на балансе» организации; контроль подписания УПД до выкладки в продажу |
| Повторная продажа одного кода | Автоштраф по данным касс (с 01.09.2026); разрешительный режим блокирует чек | Разрешительный режим на кассе; в e-commerce — блокировка КМ, уже использованного в другом заказе |
| Невывод из оборота (продали, но сведения в ЧЗ не ушли) | Расхождение остатков → штраф 1–10 тыс. (должн.), 25–100 тыс. (юрлица) | Автоматический вывод из оборота из чека/отгрузки; монитор «зависших» выбытий; контроль 3-дневного срока |
| Просроченный/неподписанный УПД (срок передачи данных — 3 раб. дня) | 1–10 тыс. (должн.), 25–100 тыс. (юрлица) | Светофор входящих УПД с дедлайнами, запрет приемки «мимо ЭДО» |
| Расхождение остатков МС ↔ ГИС МТ (пересорт, неверные возвраты) | Основание для проверки, автоштрафы | Еженедельная автоматическая сверка по GTIN + инвентаризация КМ с актом расхождений |
| Отказ разрешительного режима — кассир «продает мимо» | Штраф + конфискация | Жесткая блокировка позиции без обхода кассиром; регламент «карантинная полка → перемаркировка/возврат» |
| Отсутствие реквизита «код товара» в чеке | 1,5–3 тыс. (должн.), 5–10 тыс. (ИП/юрлица) | ФФД 1.2, запрет закрытия чека без скана КМ |
| Нечитаемый/поврежденный КМ | Товар нельзя продать | Процесс перемаркировки: заказ нового КМ, печать, ввод в оборот |

Ключевой тренд 2026: **проверки заменяются автоштрафами** — Роспотребнадзор формирует постановления по данным касс и ГИС МТ, они приходят в Госуслуги, на обжалование 10 дней. Контроль должен быть системным до чека, а не после.

## 4. Печать этикеток DataMatrix

- **Принтеры:** термопринтеры — для быстрой оборачиваемости; термотрансферные (с риббоном) — для стойких этикеток; разрешение **от 300 dpi**.
- **Форматы:** рулонные 58×40, 58×30, 43×25 мм; для остатков практикуют печать на листах А4 (36 этикеток 47×30). На флакон косметики чаще 30×20–58×40 с DataMatrix + название + GTIN.
- **Организация печати на остатки:** заказ КМ по GTIN пакетно → печать через шаблоны → оклейка → ввод в оборот. Контроль качества печати (сканер-верификация первой этикетки из партии) и допечать дубликата по скану.

## 5. UX-паттерны «защиты от дурака» для линейного персонала

1. **Пошаговые мастера операций** — сотрудник не выбирает «что делать с кодом», а идет по сценарию: «Приемка → сканируй короб → сканируй позиции → расхождения → подтверди».
2. **Жесткие блокировки, а не предупреждения** — не тот товар, лишнее количество или чужой КМ блокируется сразу со звуком/вибрацией. На кассе — невозможно закрыть чек без валидного скана.
3. **Светофор статусов** (СБИС): зеленый — код совпал с документом и статус корректен; желтый — предупреждение; красный — кода нет в документе/не прошел проверку. Сотруднику не нужно понимать статусы ГИС МТ — только цвет.
4. **Сверка в реальном времени** — счетчик «отсканировано 47 из 52» и список несовпадений по ходу сканирования.
5. **Защита от пересорта** (GetMark) — привязка КМ к конкретному товару/заказу; скан КМ от другого GTIN отклоняется.
6. **Автоматизация «за кулисами»** — вывод из оборота, наполнение УПД, отправка в ЧЗ происходят автоматически из обычных действий; сотрудник не работает с ЛК ЧЗ вообще.
7. **Понятный сценарий отказа** — при блокировке сотрудник видит причину простыми словами («Товар уже продан», «Код не введен в оборот») и инструкцию: карантинная полка / позвать ответственного.
8. **Офлайн-устойчивость** — ТСД и касса работают без интернета, очередь операций досылается автоматически.

## 6. Рекомендации для cosmex.ru

1. **База уже есть:** нативный модуль ЧЗ в МойСклад + Касса МойСклад закрывают заказ КМ, приемку по ЭДО, продажу с выводом из оборота и разрешительный режим (для офлайна нужна Windows-касса с Локальным модулем ЧЗ). Тариф — не ниже «Профессионального».
2. **Главный пробел МС, который закрывает этот проект:** (а) сценарий **дистанционной продажи** — скан КМ при сборке интернет-заказа с автоматическим выводом из оборота и контролем 3-дневного срока; (б) **регулярная сверка остатков МС ↔ ГИС МТ** по GTIN с актами расхождений; (в) **монитор ошибок/дедлайнов** (неподписанные УПД, зависшие выбытия, коды в некорректных статусах).
3. **Ориентиры для проектирования:** светофор статусов СБИС, пошаговые операции и блокировки Склад 15, массовые операции riacode, защита от пересорта GetMark.
4. **Дедлайны:** 01.07.2026 — обязательные ЭДО и вывод из оборота через кассу (ТС ПИоТ) по косметике; 01.09.2026 — автоштрафы; 01.07.2028 — поэкземплярный учет. Проектировать сразу под поэкземплярный учет, не под ОСУ.
