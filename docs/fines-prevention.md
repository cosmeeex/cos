# Карта рисков: нарушение → штраф → наш контроль

Цель проекта — чтобы каждая строка этой таблицы была закрыта автоматическим контролем, а не памятью сотрудника. С 01.09.2026 нарушения фиксируются автоматически по данным касс и ГИС МТ (постановления приходят в Госуслуги, 10 дней на обжалование) — человеческий контроль «после» больше не работает, только системный «до».

## Три правила, которые закрывают 80% рисков

1. **Ни один документ с 🔴 не проводится.** Технически: вебхуки → страж → алерт; организационно: менеджеры знают, что красный = стоп.
2. **УПД подписывается в 3 рабочих дня, товар на полку — после подписания.**
3. **Еженедельная сверка чистая.** Любое расхождение имеет имя, причину и закрывающий документ.
