# ПП № 656: маркировка товаров личной гигиены — заключение для Cosmex

Дата анализа: 27.08.2026. Источник сроков: ПП РФ от 30.05.2026 № 656 в пересказе
отраслевых обзоров (МойСклад, Truemark, Rokass); в датах второго этапа источники
расходятся (01.10 vs 01.11.2026) — на обязанности Cosmex это не влияет (мы не
производитель и не импортёр этих товаров), точную дату зафиксировать по тексту ПП.

## Календарь

| Дата | Что происходит |
|---|---|
| 01.09.2026 | Регистрация участников оборота в ЧЗ (нам — добавить товарную группу в ЛК) |
| 01.10.2026 | Производители/импортёры маркируют: бумажная санитарно-гигиеническая продукция |
| 01.10–01.11.2026 | Производители/импортёры маркируют: маникюрные наборы, пинцеты, расчёски, щётки, пемзу, массажёры и пр. |
| 30.09.2027 | Последний день продажи немаркированных остатков (закупленных до старта) |
| 01.10.2027 | Оборот немаркированных запрещён; продажи через кассу с кодом; ОСУ |
| 01.07.2030 | Поэкземплярный учёт |

«наборы и инструменты маникюрные/педикюрные, включая пилки для ногтей» покрывает и
отдельные металлические инструменты, но отраслевые разборы трактуют по-разному):

| Категория | SKU | Остаток, шт |
|---|---|---|

НЕ входит (частые страхи — зря): абразивные пилки и бафы (ТН ВЭД 6805), ножницы,
в т.ч. маникюрные и парикмахерские (8213), кисти косметические (9603 30),
безворсовые салфетки (нетканые), пустые чехлы для наборов, фрезы, лампы, зеркала.

## Что это значит для Cosmex

1. **Мы не маркируем сами**: все эти товары закупаются у российских
   поставщиков — коды наносят производители/импортёры. Домаркировка остатков
   розницей для этой группы не предусмотрена — остатки просто продаются без
   кодов до 30.09.2027.
2. **Сентябрь 2026**: добавить в ЛК Честного знака товарную группу гигиены
   (та же УКЭП, ~15 минут; как с косметикой).
3. **С октября–ноября 2026**: новые поставки пинцетов/расчёсок и пр. должны
   приходить уже с кодами и по УПД через ЭДО. Приёмка — как у косметики
   (SOP 10); страж контролирует.
4. **До 30.09.2027**: распродать немаркированные остатки. Приоритет —
   пинцеты (1476 шт) и щёточки для ресниц (843 шт): при текущих темпах продаж
   оценить, успеваем ли, и притормозить закупку немаркированных партий.
   После 01.10.2027 непроданные немаркированные остатки продавать нельзя
   (только списать/вернуть поставщику).
5. **Серая зона**: запросить у основных поставщиков инструментов (Staleks,
   Ellis Cosmetic, DEWAL и др.) коды ТН ВЭД по кусачкам/книпсерам/металлическим
   пилкам и будут ли они маркировать. По ответам обновить классификатор.
6. **Интеграция готова**: классификатор знает волну hygiene-2026 (пинцеты,
   расчёски, щётки, щёточки, брашинги, массажёры, пемза...), страж начнёт
   требовать коды по этой группе автоматически с даты обязательности; чехлы и
   ножницы из-под волны исключены.

## Дубли «(немарк.)» для этой волны

Не нужны до осени 2027: пока весь товар немаркированный, касса без признака
маркировки продаёт его как обычно. Ближе к 01.10.2027 — тот же манёвр, что с
косметикой: признак ставим только когда пойдут коды, немаркированные остатки —
через дубль.
