# Маркировка «Честный знак»: парфюмерия, косметика, бытовая химия — состояние на август 2026

> Исследование от 19.08.2026 по открытым источникам. Факты с неполной уверенностью собраны в последнем разделе — их нужно сверить с первоисточниками перед боевым запуском.

---

## 1. Парфюмерия (духи и туалетная вода)

**Нормативная база:** Распоряжение Правительства РФ от 28.04.2018 № 792-р (перечень товаров), Постановление Правительства РФ от 31.12.2019 № 1957 (правила маркировки духов и туалетной воды).

**Коды:** ТН ВЭД ЕАЭС **3303 00**; ОКПД2 **20.42.11** (духи — 20.42.11.110, туалетная вода — 20.42.11.120, одеколоны — 20.42.11.130).

**Ключевые даты (давно действуют):**
- **С 01.10.2020** — запрет производства/импорта без кодов DataMatrix.
- **До 30.09.2021** — разрешалась продажа немаркированных остатков; **с 01.10.2021** продажа немаркированной парфюмерии полностью запрещена.
- **1–31 октября 2021** — окно маркировки остатков по упрощённой схеме (5 атрибутов). **С 01.12.2021** — запрет реализации промаркированных, но не введённых в оборот остатков. Новых окон для остатков в 2022–2026 не вводилось.
- **С 01.01.2022** — оборот только через ЭДО (УПД), учёт **поэкземплярный**.

**Исключения:** пробники и тестеры **до 3 мл включительно**; выставочные образцы; духи в твёрдой форме; экспорт. (Одна статья упоминает «до 5 мл» — это норма для косметики по ПП № 1681; для духов действует 3 мл, сверить редакцию ПП 1957.)

**Для Cosmex:** классической парфюмерии в ассортименте нет (см. assortment-analysis.md). Мисты NOIR — неспиртовые (подтверждено владельцем 19.08.2026) → не 3303, а косметика (3307/3304): группа «парфюмерия» Cosmex не касается вовсе.

## 3. Остатки (ответ на вопрос «как продавать товар без маркировки»)

- **Парфюмерия (ПП 1957):** все сроки истекли — немаркированные духи/туалетная вода сегодня вне закона, окон домаркировки нет.
- **Косметика и бытхимия этапов 2025 г. (ПП 1681):** обязательной маркировки остатков **НЕТ**. Товары, произведённые/ввезённые **до контрольной даты своего этапа**, продаются без кодов **до истечения срока годности**. Упрощённой схемы описания остатков не требуется; добровольная маркировка возможна (заказ КМ с способом ввода в оборот «маркировка остатков»).
- **Практическое следствие:** ключ к легальной продаже немаркированных остатков — **доказуемая дата производства/ввоза** (партии, накладные, декларации). Товар, произведённый после даты волны и пришедший без кодов, продавать нельзя — возврат поставщику или (для собственного импорта) маркировка импортёром.
- **Бритвы и лезвия:** домаркировка остатков до 30.11.2026 (по др. источнику — 31.01.2027, сверить); запрет оборота немаркированных — с 01.12.2026.
- **Гигиеническая волна 2026 (ПП 656):** продажа немаркированных остатков и домаркировка — до **31.10.2027**.

## 4. Разрешительный режим на кассах

**База:** ПП РФ от 21.11.2023 № 1944 (изм. ПП № 1606 от 22.11.2024; для косметики — в ред. **ПП № 161 от 19.02.2026**).

- **Парфюмерия:** онлайн-проверка обязательна с 01.11.2024; офлайн — с 01.03.2025.
- **Косметика, бытхимия, личная гигиена:** разрешительный режим — **с 01.04.2027**. (Статьи про «с 01.07.2026» путают с обязанностью сканировать код на кассе и передавать вывод из оборота — она действует с 01.07.2026, но запрета продажи по результату онлайн-проверки до 01.04.2027 нет.)
- **Что проверяется:** наличие КИ в системе, ввод в оборот, не выведен ли ранее, блокировка, криптоподпись, срок годности. Ответ до 1,5 сек.
- **Офлайн:** решение по локальной базе кассы; на устранение сбоя — 72 часа; база блокировок обновляется каждые 2 часа.

## 5. Штрафы

- **Ст. 15.12 КоАП, производство без маркировки:** должн. лица/ИП 5–10 тыс. ₽; юрлица 50–100 тыс. ₽ + **конфискация**.
- **Ст. 15.12 КоАП, продажа/хранение/перевозка без маркировки:** граждане 2–4 тыс.; должн./ИП 5–10 тыс.; юрлица 50–300 тыс. ₽ + **конфискация**.
- **Ст. 15.12.1 КоАП (непередача/нарушение сроков/недостоверные сведения в ГИС МТ):** должн./ИП 1–10 тыс.; юрлица 50–100 тыс. ₽.
- **Нарушение разрешительного режима:** 1–10 тыс. должн., 50–100 тыс. юрлица.
- **УК РФ ст. 171.1** (крупный размер, поддельные коды): до 3–6 лет + штраф до 1 млн ₽. Пороги (2026): крупный — свыше 3,5 млн ₽, особо крупный — 13,5 млн ₽ (сверить редакцию).
- **Автоштрафы с 01.09.2026:** нарушения фиксируются автоматически по данным ГИС МТ/касс без выездной проверки, постановления приходят в Госуслуги/ФНС; продажа просрочки: ИП 10 тыс. ₽/ед., юрлица 20 тыс. ₽/ед.

## 6. Электронная торговля

- **Свой интернет-магазин (курьерка/ПВЗ):** вывод из оборота — документ «Вывод из оборота» с причиной **«дистанционный способ продажи»** при отгрузке со склада, **не позднее 3 рабочих дней с отгрузки и не позднее дня вручения**. Коды курьерской службе не передаются. Чек при предоплате: первый без кода, второй (передача) с кодом; при оплате при получении — один чек с кодом.
- **Маркетплейсы (с 01.03.2023 — участники оборота):** FBO — селлер передаёт товар по УПД с кодами через ЭДО, вывод из оборота передаёт **маркетплейс**; FBS/DBS — вывод из оборота — **обязанность селлера**.
- 2026: WB и Ozon автоматически проверяют коды до публикации карточек; товары без валидной маркировки блокируются на модерации.

## 8. Технические API «Честного знака»

**True API (ГИС МТ)** — документация v.719.0 от 18.08.2026, docs.crpt.ru:
- Прод: `https://markirovka.crpt.ru/api/v3/true-api` (и `/api/v4/true-api`).
- Песочница: `https://markirovka.sandbox.crptech.ru/api/v3/true-api` (и v4).
- Аутентификация УКЭП: `GET /auth/key` (uuid + data) → подписать data УКЭП (CMS, base64, КриптоПро CSP) → `POST /auth/simpleSignIn` → Bearer-токен, живёт **до 10 часов**. В 2026 идёт переход с JWT на UUID-токен (оба поддерживаются).
- Методы: подача документов (ввод в оборот, вывод, возвраты), статусы КИ (`cises/info`), выгрузки, ЭДО Лайт, разрешительный режим (`codes/check`).

**СУЗ (заказ кодов):**
- Прод: `https://suzgrid.crpt.ru/` (API v3: `/api/v3/order`, `/order/status`, `/codes`, `/ping`, параметр `omsId`). Песочница: `https://suz.sandbox.crptech.ru/`. API СУЗ 2.0 отключён с 01.09.2024.
- Аутентификация: клиентский токен СУЗ + omsId + зарегистрированное устройство эмиссии.
- **Цена кода:** 50 коп. без НДС (ПП № 577 от 08.05.2019); с 01.01.2026 НДС 22% → **61 коп. с НДС**.

**Национальный каталог (GTIN, карточки):**
- Прод: `https://апи.национальный-каталог.рф`; песочница: `https://api.nk.sandbox.crptech.ru`.
- Аутентификация: `apikey` из ЛК НК или Bearer-токен ГИС МТ.
- Методы: `POST /v3/feed` (карточки, до 25 МБ), `/v3/feed-status`, `GET /v3/product?gtin=…`, `/v4/product-list`, `/v3/mark-check`. Лимит: 500 запросов/5 мин (429 + Retry-After).

## Факты с неполной уверенностью (сверить перед продакшном)

1. Порог пробников парфюмерии: 3 мл (принято) vs «до 5 мл» в одной статье — сверить редакцию ПП 1957.
2. Срок домаркировки остатков бритв/лезвий: 30.11.2026 vs 31.01.2027.
3. Даты волны ПП № 656: старт «оборотных» обязанностей 01.10.2027 vs 01.11.2027; регистрация с 01.09.2026.
4. Этапы автофиксации нарушений: устойчивая дата — 01.09.2026; номер «ФЗ № 120-ФЗ от 02.05.2026» подтверждён одним источником.
5. Пороги ст. 171.1 УК (3,5/13,5 млн) — выверить по КонсультантПлюс.
6. Номер ПП о маркетплейсах-участниках оборота с 01.03.2023 — не назван в источниках.
7. Точные перечни исключений ТН ВЭД в этапах ПП 1681 (напр., «кроме 3304 99 000 0») — брать из приложений к ПП в действующей редакции.
8. Сроки «домаркировки» переходных окон 2025 г. (30.06.2025 мыло, 31.08.2025 волосы, 30.11.2025 косметика — по данным 1С) — сверить с текстом ПП 1681.
