# Маркировка для менеджера Cosmex: основы

> Прочитайте один раз — дальше работают короткие инструкции по операциям (файлы 10–60).

## Что такое маркировка и почему это важно

На каждой единице маркируемого товара — квадратный код **DataMatrix** (не путать с обычным полосатым штрихкодом и с QR). Государство (система «Честный знак») отслеживает путь каждой единицы: производитель → поставщик → мы → покупатель. Каждое движение мы обязаны отражать. За ошибки — штрафы до 300 тыс. ₽ с конфискацией, причём **с 01.09.2026 штрафы выписываются автоматически** по данным касс, без проверки.

## Что из нашего ассортимента маркируется

| Уже обязательно | С какой даты |
|---|---|
| Мыло, гели для душа (NOIR/Syre) | выпуск с 01.05.2025 |
| Шампуни, бальзамы, маски для волос, краски, дезодоранты, средства для/после бритья, воски для депиляции | выпуск с 01.07.2025 |
| **Гель-лаки, базы, топы, праймеры, лаки, полигели, акрилы**, кремы, масла для кутикулы, сыворотки, маски для лица, декоративная косметика, зубные пасты | выпуск с 01.10.2025 |
| Кожные антисептики (Алмадез и др.) | давно (2024) |
| **С 01.11.2026 добавятся:** пинцеты, расчёски, маникюрные наборы, мочалки, вата | готовимся |

**НЕ маркируются:** фрезы, пилки, бафы, кусачки, ножницы, аппараты, лампы, стерилизаторы, стразы, слайдеры, типсы, кисти, перчатки, крафт-пакеты, свечи, отдушки, пустая тара.

**Важно про даты:** маркируется товар, **произведённый/ввезённый после** даты волны. Товар, выпущенный раньше, законно продаётся **без кода до конца срока годности** — но мы должны уметь доказать дату выпуска (партия, накладная).

## Светофор

Интеграция проверяет каждый документ и показывает светофор (панель «Страж маркировки», уведомления в Telegram):

- 🟢 **Зелёный** — всё в порядке, работайте дальше.
- 🟡 **Жёлтый** — предупреждение: прочитайте текст, там написано, что проверить.
- 🔴 **Красный** — СТОП: документ проводить нельзя. В тексте — что именно исправить. Не можете исправить — зовите ответственного за маркировку.

## Пять золотых правил

1. **Каждой единице — свой скан.** Продаёте 3 флакона одного гель-лака — сканируете 3 разных кода. Никогда не сканируйте один флакон трижды.
2. **Сканируйте с той упаковки, которую отдаёте.** Код с соседней коробки = продажа чужого кода = штраф.
3. **Ничего «мимо кассы» и «мимо ЭДО».** Приёмка маркированного товара — только через УПД в ЭДО (обязательно с 01.07.2026). Продажа — только со сканом на кассе или через оформленный интернет-заказ.
4. **Проблемный товар — на карантинную полку.** Код не читается, касса ругается, товар без кода, который должен быть с кодом — не продавать, отложить, позвать ответственного. Записка: что, откуда, когда.
5. **Не подгонять.** Расхождение в остатках решается поиском причины, а не «списанием для красоты». Каждый вывод из оборота — с реальной причиной.
