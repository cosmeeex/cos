# Приёмка маркированного товара

**Когда:** приехала поставка от поставщика, в которой есть маркируемые позиции (гель-лаки, шампуни, кремы и т.д. — см. 00-osnovy.md).

## Правильный путь (обязателен с 01.07.2026): через ЭДО

1. Поставщик отправляет **УПД с кодами маркировки** через ЭДО (ЭДО Лайт / Такском / 1С:Клиент ЭДО). Если поставщик прислал только бумажную накладную — **не принимайте маркированный товар**, свяжитесь с ним: «нужен УПД через ЭДО».
2. В МойСклад: **Закупки → Приемки → ЭДО → Импорт** — выберите документ, организацию и склад. Создастся Приёмка с кодами на позициях.
3. **Сверка:** откройте Приёмку → «Проверить коды в ГИС МТ». Смотрите на цвета:
   - все зелёные → шаг 4;
   - есть красные/жёлтые → сканируйте физический товар и сверяйте: чего-то не хватает, что-то лишнее? Внесите расхождения в документ, сообщите ответственному. **УПД с расхождениями не подписываем**, пока не согласовали с поставщиком (исправленный УПД или УКД).
4. Выборочно (5–10 коробок из партии) отсканируйте коды с товара и убедитесь, что они есть в документе. Пересорт от поставщиков — частая история.
5. Подпишите УПД в системе ЭДО. **Срок — 3 рабочих дня с поставки**, не тяните: неподписанный УПД = коды числятся за поставщиком = наш товар нельзя продавать.
6. Проведите Приёмку. Светофор в панели должен стать 🟢.

## Товар пришёл без кодов

- Позиция маркируемая, выпуск **после** даты волны, кодов нет → **не принимать**, товар в карантин, ответственному: возврат поставщику или требование домаркировки поставщиком.
- Выпуск **до** даты волны (смотрим дату производства на упаковке/в документах) → принимать можно, товар продаётся без кода до конца срока годности. Сохраните документ, подтверждающий дату выпуска.
- Наш собственный импорт СТМ COSMEX (Казахстан) → это отдельный процесс, см. 30-residuals.md: маркируем сами как импортёр **до** начала продаж.

## Частые ошибки

| Ошибка | Чем грозит | Как правильно |
|---|---|---|
| Принять «по бумажке», разнести руками | Коды остаются у поставщика; продажа = «чужой код», штраф | Только импорт УПД из ЭДО |
| Подписать УПД не сверив | Приняли «мёртвые»/чужие коды | Сначала проверка кодов, потом подпись |
| УПД висит неподписанным неделю | Нарушение сроков передачи сведений (ст. 15.12.1) | Подписать в 3 рабочих дня |
| Выложить товар в продажу до подписания УПД | Касса/разрешительный режим не пропустит, продажа мимо | Сначала подпись УПД, потом на полку |
