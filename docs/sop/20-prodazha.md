# Продажа маркированного товара

## В рознице (Касса МойСклад)

1. Пробиваете товар как обычно. Для маркируемой позиции касса сама попросит **отсканировать DataMatrix** — сканируйте код **с той единицы, которую отдаёте покупателю**.
2. Несколько одинаковых товаров → каждый сканируется отдельно. Касса не даст закрыть чек, пока кодов меньше, чем товаров.
3. Касса проверяет код в «Честном знаке». Если **отказ** (код не найден / уже продан / заблокирован / просрочен):
   - НЕ пытайтесь пробить «как обычный товар», без кода или через «свободную продажу» — это фиксируется и штрафуется автоматически;
   - возьмите другую единицу с полки, а проблемную — на карантинную полку с запиской;
   - сообщите ответственному: обычно это неподписанный УПД, пересорт или нужна перемаркировка.
4. Чек закрылся — всё: вывод из оборота ушёл автоматически через кассу/ОФД. Ничего дополнительно делать не нужно.

### Единица без кода (законный остаток, выпущенный до волны маркировки)

Официальный ответ поддержки МойСклад (26.08.2026): продавать такой товар через основную
(маркированную) карточку нельзя — в том числе вводом кода «0» (он уйдёт в Честный знак
как код маркировки и создаст ошибки, ведущие к штрафам).

Продажа немаркированного остатка идёт через **карточку-дубль** с пометкой «(немарк.)»
и без признака маркировки. Дубли создаёт и закрывает интеграция — кассиру нужно знать одно
правило:

- на флаконе ЕСТЬ DataMatrix → пробиваем обычную карточку, сканируем код;
- кода НЕТ → сначала внимательно осмотрите дно, крышку и защитную плёнку (DataMatrix
  часто прячется там); если кода точно нет — ищем в кассе карточку с «(немарк.)»
  в названии и пробиваем её без сканирования;
- карточки «(немарк.)» нет, а кода на товаре нет → НЕ продавать, товар ответственному.

Продать маркированный флакон через карточку «(немарк.)» — нарушение (его код повиснет
в обороте): за этим следит еженедельная сверка, но правило кассира — первая линия защиты.

## Интернет-заказ (доставка курьером/ПВЗ/транспортной)

При дистанционной продаже вывод из оборота НЕ происходит сам — это наша обязанность в момент отгрузки со склада.

1. Собирая заказ, **отсканируйте код каждой маркируемой единицы в позиции Отгрузки** в МойСклад (страж проверит комплектность — светофор 🟢).
2. Проведите Отгрузку. Интеграция отслеживает: по каждой отгрузке с кодами должен появиться документ **«Вывод из оборота» с причиной «Дистанционная продажа»**.
   - Если настроен автоматический режим — интеграция создаст документ сама, менеджеру остаётся проверить и отправить в ЧЗ (кнопка в МойСклад).
   - **Срок жёсткий: 3 рабочих дня с отгрузки и не позднее дня вручения.** Просрочки видны в панели и приходят в Telegram — реагируйте в тот же день.
3. Кассовый чек: при предоплате на сайте первый чек уходит без кода, чек при передаче — с кодом; это настраивается в кассовом модуле, коды подтягиваются из отгрузки.
4. Курьерской службе коды не передаются — они наши.

## Продажа через маркетплейсы (если появится)

- **FBO** (со склада маркетплейса): отгружаем на маркетплейс по УПД с кодами через ЭДО; вывод из оборота делает маркетплейс.
- **FBS/DBS** (с нашего склада): вывод из оборота — **наша обязанность**, как при обычном интернет-заказе.
- С 2026 Ozon/WB блокируют карточки без валидной маркировки на модерации.

## Оптовая продажа (салонам, ИП)

Опт юрлицу/ИП — это не «вывод из оборота», а **передача кодов покупателю по УПД через ЭДО** (как приёмка, только наоборот): отгрузка в МойСклад с кодами → экспорт УПД → подпись обеих сторон. Если покупатель берёт «для собственных нужд» (салон сам расходует материал), возможен вывод из оборота «для собственных нужд покупателя» — уточните у ответственного, как оформляем конкретного клиента.
