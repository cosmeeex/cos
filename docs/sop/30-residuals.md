# Товар без кодов: остатки, собственный импорт, домаркировка

## Сначала — определить, почему товар без кода

| Ситуация | Что делать |
|---|---|
| Выпущен **до** даты своей волны (мыло — до 01.05.2025, волосы — до 01.07.2025, ногти/уход — до 01.10.2025) | **Продавать можно без кода** до конца срока годности. Ничего маркировать не обязательно. Сохранить документы с датой выпуска/ввоза. По желанию — домаркировать (ниже), чтобы не спорить с проверкой. |
| Выпущен **после** даты волны, куплен у российского поставщика без кодов | Продавать **нельзя**. Карантин → претензия поставщику: возврат или его домаркировка. Мы не имеем права маркировать чужой недомаркированный товар. |
| **Наш импорт** (СТМ COSMEX из Казахстана, Cos De Baha из Кореи и т.п.), выпущен после волны | Мы — импортёр, маркируем **сами и до начала оборота в РФ** (для ЕАЭС — до пересечения границы либо до начала продаж, сверяйтесь с актуальными правилами ввоза). Способ ввода: «Ввезён в РФ» (FOREIGN). |
| Личная гигиена (пинцеты, расчёски, маникюрные наборы…) выпуска до 01.11.2026 | Домаркировка остатков разрешена **до 31.10.2027** — план и коды готовит интеграция заранее. |
| Код был, но этикетка повреждена/не читается | Перемаркировка (см. 60-spisanie.md). |

## Конвейер домаркировки (полуавтоматический)

Интеграция готовит всё сама, менеджер выполняет 4 действия в МойСклад.

**Подготовка (делает интеграция / ответственный):**

```
node src/cli.ts plan-residuals            # план: какие товары, сколько кодов, цена
node src/cli.ts plan-residuals --create   # создать документы «Заказ КМ» в МойСклад
```

План лежит в `reports/residuals-plan.md`: там же список карточек, которые сначала нужно починить (нет GTIN — завести штрихкод и описать товар в Национальном каталоге).

**Действия менеджера в МойСклад (Розница → Маркировка → Заказы кодов):**

1. Открыть документ «ОСТАТКИ-001 …» → кнопка **«Заказать коды»**. Дождаться статуса «Коды получены» (обычно минуты).
2. **«Печать»** → печатаются этикетки с DataMatrix (принтер этикеток, формат 58×40).
3. **Наклеить** этикетки на товар, СВЕРЯЯ название на этикетке с товаром. Один товар — одна этикетка, не путать между позициями! Наклеивать так, чтобы не повредить (не на шов, не на крышку).
4. В документе → **«Создать ввод в оборот»** → провести. Только после этого товар можно продавать.

**Жёсткие сроки:** полученные коды живут максимум **120 дней** — если не наклеить и не ввести в оборот, они сгорают (и деньги за них). Заказывайте партиями, которые реально успеете оклеить за неделю-две.

**Цена вопроса:** 0,61 ₽ за код (50 коп. + НДС 22%). План показывает итоговую сумму до заказа.

## Мост до завершения домаркировки: карточки-дубли «(немарк.)»

Пока партия остатков не оклеена кодами, продавать её можно только через карточку-дубль
(официальная рекомендация поддержки МойСклад). Порядок автоматизирован интеграцией:

1. Интеграция строит отчёт «немаркированные остатки» (оценка по датам приёмок) и создаёт
   дубли только для товаров, где такие остатки реально есть.
2. Остаток переносится на дубль парой документов (списание с основной + оприходование
   на дубль) — это делает интеграция, вручную ничего не двигать.
3. Немаркированные единицы выставляются на полке вперёд (продаём их первыми, FIFO).
   Стикер «остаток» — по желанию, для ходовых позиций, где много одинаковых флаконов.
4. Когда немаркированный остаток распродан или оклеен кодами — интеграция обнуляет
   и архивирует дубль. Дубли-долгожители всплывают в еженедельном отчёте.

## Контроль качества

- Первую этикетку из каждой партии отсканируйте сканером: код читается, товар в скане совпадает (команда `node src/cli.ts scan <код>` или проверка на кассе в режиме «проверка»).
- После оклейки партии — выборочно 5–10 штук.
- Испорченные при печати/наклейке этикетки не выбрасывать молча: список кодов — ответственному (их нужно списать в ЧЗ, см. 60-spisanie.md).
