# Наборы и комплекты

У Cosmex есть наборы из маркируемых товаров: «шампунь + бальзам 2×1000 мл», NOIR «Вселенная аромата» (гель + шампунь + мист + крем) и подарочные. С ними два законных варианта.

## Вариант А: набор = несколько товаров с их кодами (проще, наш выбор по умолчанию)

Набор в МойСклад — «Комплект» из отдельных товаров. Каждое вложение уже имеет свой код (от производителя или нашей домаркировки).

- **Продажа:** кассир/сборщик сканирует **все** коды вложений (для «Вселенной аромата» — 4 скана). Касса сама разложит комплект в чеке.
- **Плюсы:** ничего дополнительно не оформлять; можно продавать вложения и по отдельности.
- **Минусы:** несколько сканов на кассе.

## Вариант Б: свой код на набор (КИТУ/комплект в ЧЗ)

Набор собирается заранее, в «Честном знаке» оформляется агрегация/комплект, на коробку клеится единый код.

- Нужен GTIN на сам набор, карточка в Нацкаталоге, операция агрегации в МойСклад (Формирование упаковки).
- Разбор набора (продать вложение отдельно) требует расформирования упаковки в ЧЗ.
- Используем только для массовых, заранее собираемых наборов. Решение — за ответственным за маркировку.

## Правила для сборщика

1. Собирая набор, кладите внутрь именно те единицы, чьи коды отсканированы в заказ. Не менять флакон в последний момент без пересканирования!
2. Если у части вложений кода нет (старые остатки до волны) — это нормально: сканируются только маркированные вложения. Страж подскажет, сколько кодов ждёт.
3. Подарочная упаковка не должна закрывать DataMatrix вложений, если код на набор не оформлялся (вариант А): курьер/касса должны иметь возможность отсканировать. Либо коды сканируются ДО упаковывания — при сборке заказа.
