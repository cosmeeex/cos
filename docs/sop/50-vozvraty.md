# Возвраты

## Возврат от розничного покупателя (чек нашей кассы)

1. Оформляйте **«Возврат» через Кассу МойСклад по чеку продажи** — только так код автоматически вернётся в оборот через ОФД.
2. Обязательно отсканируйте DataMatrix возвращаемой единицы. Код на упаковке должен совпасть с проданным — если покупатель принёс «такой же, но другой» товар (код не совпадает), это НЕ возврат этого чека: зовите ответственного.
3. Если этикетка с кодом утрачена/повреждена (упаковка вскрыта, код стёрт):
   - возврат оформляется, но код в оборот не вернётся автоматически;
   - товар — на карантинную полку: дальше либо перемаркировка (60-spisanie.md), либо списание, решает ответственный.
4. Товар после возврата снова продаётся только если он введён в оборот (проверка сканером/на кассе).

## Возврат по интернет-заказу (покупатель отказался / невыкуп)

- Если вывод из оборота **ещё не подавался** (заказ не уехал / вернулся до подачи) — просто отмените отгрузку, ничего в ЧЗ делать не нужно; интеграция увидит отмену и снимет задачу.
- Если вывод из оборота **уже подан** — нужен «Возврат в оборот» в МойСклад (Розница → Маркировка) на конкретные коды. Основание — заявление/документ возврата. Делает ответственный, менеджер передаёт коды и документ.

## Возврат поставщику

Маркированный товар возвращается поставщику **с кодами по УПД через ЭДО** (обратная передача). Не «списывайте» товар, который фактически уехал поставщику — коды должны сменить владельца, а не исчезнуть.

## Чего не делать никогда

- Не принимать возврат «без чека и без скана» по маркированному товару.
- Не выкладывать возвращённый товар на полку без проверки, что его код снова «в обороте».
- Не возвращать в оборот код, если сам товар не вернулся (это фиктивная операция).
