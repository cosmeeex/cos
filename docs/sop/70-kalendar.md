# Календарь ответственного за маркировку

## Ежедневно (5 минут)

- [ ] Панель «Страж маркировки»: нет 🔴? Все вчерашние документы зелёные?
- [ ] Telegram: отработаны все алерты (просроченные выводы из оборота — в первую очередь).
- [ ] Карантинная полка: разобраны вчерашние находки (перемаркировка/возврат/претензия).
- [ ] Входящие УПД в ЭДО: нет ли неподписанных старше 1 дня.

## Еженедельно (30 минут)

- [ ] `node src/cli.ts reconcile` — сверка остатков МС ↔ ЧЗ; разобрать каждое расхождение из `reports/reconcile.md` (или дождаться автоматического отчёта в Telegram).
- [ ] `node src/cli.ts distance` — все дистанционные продажи закрыты выводом из оборота.
- [ ] Заказы КМ в работе: наклеены ли полученные коды, не приближается ли лимит 120 дней.

## Ежемесячно

- [ ] `node src/cli.ts audit` — новые товары классифицированы, карточки без GTIN/ТН ВЭД починены.
- [ ] Список истекающих сроков годности → уценка/списание.
- [ ] Выборочная инвентаризация: отсканировать 20–30 случайных маркированных товаров с полки — все «в обороте» и наши? (красный статус = разбирательство).
- [ ] Баланс лицевого счёта ЧЗ: хватает ли на эмиссию кодов (0,61 ₽/код).

## По событиям нормативки (даты уже в системе)

- **01.09.2026** — автоштрафы: к этой дате все сверки должны быть чистыми.
- **01.11.2026** — стартует маркировка пинцетов/расчёсок/маникюрных наборов: провести аудит этих категорий, зарегистрировать товарную группу в ЛК ЧЗ (регистрация с 01.09.2026), спланировать остатки (окно до 31.10.2027).
- **01.04.2027** — разрешительный режим на кассе для косметики: убедиться, что токен ККТ прописан, локальный модуль для офлайна установлен, кассиры проинструктированы (20-prodazha.md).
- **01.07.2028** — поэкземплярный учёт в УПД для косметики: к этому моменту весь учёт уже ведём поэкземплярно, переход должен быть незаметным.
